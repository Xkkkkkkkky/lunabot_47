# Codex雷达查询服务 (codexradar)

查询模型各推理档位的雷达分，模型和档位跟随数据源更新。

## 指令目录

### 查询总雷达分
`/codexradar`
> 返回总雷达分图片，包含模型各推理档位的雷达分、已正式判分题次、平均 API 等价费用（美元）和平均耗时。

### 查询分项雷达分
`/codexradar se` `/codexradar vis` `/codexradar term` `/codexradar sci`
> 分别查询软件工程、视觉空间推理、终端与系统操作、科学研究，返回对应的紧凑分项图片。
